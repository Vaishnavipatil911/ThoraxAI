🫁 AI-Powered Pneumonia Detection System
An end-to-end Computer Vision application that analyzes chest X-ray images to detect pneumonia. Built using pre-trained deep learning models from Hugging Face and delivered via an intuitive Streamlit web interface.

📌 Overview
Early detection of respiratory conditions like pneumonia is critical in healthcare. This system offers a fast, accessible tool that classifies input chest X-rays into Pneumonia or Normal categories, providing instant diagnostic predictions alongside confidence percentages to assist in interpreting model certainty.


✨ Key Features
Instant Diagnostic Predictions: Upload chest X-rays and receive real-time classification.
Confidence Scoring: Displays model output probabilities as a clear percentage.
Hugging Face Integration: Leverages state-of-the-art vision models fine-tuned for medical imaging.
Simple Web Interface: Clean, accessible UI designed using Streamlit.
Lightweight Pipeline: Preprocesses images automatically for reliable inference.

🛠️ Tech Stack
Language: Python 3.8+
Deep Learning Frameworks: PyTorch, Hugging Face transformers
Web UI: Streamlit
Image Processing: Pillow (PIL), NumPy

⚙️ Quick Start
1. Clone the Repository
git clone https://github.com/Vaishnavipatil911/Pneumonia_detection
cd pneumonia-detection

2. Set Up a Virtual Environment
On Windows:
python -m venv venv
venv\Scripts\activate

On macOS/Linux:
python3 -m venv venv
source venv/bin/activate

3. Install Dependencies
pip install -r requirements.txt

4. Launch the App
streamlit run app.py

📸 How It Works
1. Upload: Select and upload a chest X-ray image (.jpg, .jpeg, or .png).
2. Preprocess: The application resizes and normalizes the image for tensor compatibility.
3. Inference: The pre-trained Hugging Face vision model evaluates the feature maps.
4. Results: The web UI renders the classification outcome and confidence score:

The confidence percentage is shown.

🧠 Model Information

This project uses a pre-trained Computer Vision model from Hugging Face for medical image classification.

🧠 Model Information
The core model is a pre-trained Vision Transformer / Convolutional Neural Network retrieved via Hugging Face.

Input: Standardized chest X-ray images

Feature Extraction: Deep layer representations tailored to radiographic patterns

Output: Softmax probability distribution over binary classes (Normal vs. Pneumonia)
