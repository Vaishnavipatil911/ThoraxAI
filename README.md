Pneumonia Detection 
📌 Project Overview

This project is an AI-powered Pneumonia Detection System that analyzes chest X-ray images and predicts whether a patient has Pneumonia or Normal lungs. The system utilizes a pre-trained Hugging Face Computer Vision Model for image classification and provides the prediction along with a confidence percentage to help interpret the model's certainty.

The application offers a simple and user-friendly interface where users can upload chest X-ray images and receive instant diagnostic predictions.

🚀 Features

Uses a pre-trained Hugging Face deep learning model.

🧠 Model Information

This project uses a pre-trained Computer Vision model from Hugging Face for medical image classification.

The model:

Accepts chest X-ray images as input.
Extracts image features using deep learning.
Classifies images into Normal or Pneumonia categories.
Returns prediction probabilities used to calculate confidence percentages.
